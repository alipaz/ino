## Review focus

Readiness must fail quickly when PostgreSQL is down and recover after restart.
Startup must not serve before PostgreSQL responds, and must stop on a signal.
No DSN, credentials or panic content should appear in HTTP responses/logs.
Shutdown must finish HTTP requests before closing the pool.
Compose must work without `.env`, publish only the API locally, and isolate data.
